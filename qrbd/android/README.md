# QRBD Android Print companion

Native Kotlin app source, Android API 26+, target/compile 35. Requires Android
Studio, JDK 17 and Android SDK 35. Open this directory in Android Studio; sync
Gradle or use a locally installed Gradle 8.9 (`gradle :app:assembleDebug`). No
wrapper JAR, APK or Android SDK binaries are committed.

**Not built or tested on a real Android device in this Linux sandbox.**
Install a compatible vendor/Mopria Android print service. Enter the deployed
QRBD HTTPS origin and a device token generated by the shop owner. Tap the button
to claim a paid order. Verify color, paper, duplex, printer and **copies** in the
Android system print dialog. Android's public PrintManager API does not let the
app preset copies. Printing is user-mediated, not silent background printing.

Only one enabled device token per shop. Generating a new token revokes the old
Windows/Android device. The token is memory-only, never backed up. A claim is
not automatically repeated. After app termination or uncertain output, reconcile
the dashboard before retrying. The server flags unresolved claims after 15 min.

This is **not** a universal USB/OTG printer driver. Raw OTG support requires
model/protocol-specific drivers and hardware verification. Wi-Fi/USB availability
depends on the installed Android print service. All-page printing only; subset
selection fails explicitly rather than printing unintended pages. 4x6 photo
paper is the Android default for photo jobs; select A4 manually for A4 sheets.
